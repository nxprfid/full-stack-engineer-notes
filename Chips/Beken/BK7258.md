# BK7258 笔记

## 芯片简介

BK7258 是一颗 WiFi 6 低功耗音视频 SoC（WiFi6 Low Power Audio and Video SoC），单芯片内集成双核 MCU、2.4 GHz 无线连接、音视频编解码、显示加速与丰富外设。

典型应用：带屏智能音箱、可视门铃、便携相机、Story Machine、低功耗 IPC 等需要**联网 + 显示/摄像头 + 音频**的 IoT 产品。

**无线连接**

| 项目 | 规格 |
| --- | --- |
| Wi-Fi | 802.11b/g/n/ax 1×1，2.4 GHz，20/40 MHz 带宽 |
| 蓝牙 | Bluetooth LE 5.4 |
| 共存 | 支持 BT/Wi-Fi 共存（PTA） |

**CPU**

| --- | --- |
| 内核 | ARM Cortex-M33 双核，最高 480 MHz |
| TCM | 16 KB ITCM + 16 KB DTCM |
| 安全扩展 | 集成 TrustZone |

**存储**

| 项目 | 规格 |
| --- | --- |
| SRAM | 640 KB |
| Flash | 最高 16 MB（外扩） |
| PSRAM | 最高 16 MB（外扩） |

**视频 / 音频 / 显示**

| 类别 | 规格 |
| --- | --- |
| 视频 | JPEG Codec、H.264 Encoder；8-bit CIS DVP、UAC |
| 音频 | 2× Audio ADC、1× Audio DAC；1× DMIC、3× I2S |
| 显示 | RGB565、RGB888、8080；硬件加速 Rotation、Scaling/Resize、DMA2D |

**外设接口**

| --- | --- |

| 其它 | 1× CAN、1× LIN、1× Ethernet MAC |
| 定时/DMA | 12× 32-bit PWM、2× GDMA |

**安全 / 电源**

| 项目 | 规格 |

| 安全 | Secure Boot、Secure Debug、Secure Connection、FOTA、Provisioning、TEE_M；PSA Certified Level 2 |
| 供电 | VBAT 2.5～4.35 V，片内 DC-DC 与 LDO |

## 模组硬件设计要点

### 电源设计

- 供电方式：单电源供电，由模组 3V3 引脚接入，工作电压范围 2.5V～4.35V，**建议使用 3V3 电压输入**
- 电流需求：
  - WiFi 保活待机：约 80μA
  - 深度休眠：约 20μA
  - 正常供电：单模组整机供电电流需 ≥ 500mA
- 退耦电容：推荐 10μF + 100nF 低 ESR 电容组合，尽量贴近 3V3 引脚布局
- 射频工作时存在脉冲电流，电源需具备快速响应能力
- DCDC/LDO 供电：输出 3V3、输出电流 > 500mA；电源模块远离射频天线区域，敏感信号线（射频/时钟）与 DCDC 保持 ≥ 20mm 间距，电源区域铺完整地平面

### 烧录调试通道

- **下载通道**：使用 P11 与 P10 GPIO 进行程序烧录（UART0）
- **日志通道**：UART0（P11/P10）可用于固件烧录与日志输出
- **SWD 调试**：P20 与 P21（SWCLK、SWDIO）
- **波特率**：固件下载默认 2000000 bps；日志输出常用 115200 bps
- CH340K 最大速率 2M（下载波特率需 < 2M bps）；CH343P 最大速率 6M（TQFN 封装对焊接能力有要求）
- 严禁使用 5V 电平串口设备直接连接调试，必须使用 3.3V 电平串口工具

### 复位方式

- 断电复位：切断模组供电后重新上电，强制全系统复位
- 引脚复位：模组预留 RTS 复位引脚，拉低电平触发复位；模组内部已集成 10K 上拉电阻，外部无需增设

## 开发环境搭建

- 环境：VMware Workstation 17 Pro + Ubuntu 22.04 以上（本文档使用 ubuntu-22.04.5-desktop-amd64）
- 安装 Git 并配置用户信息：

```bash
sudo apt install git
git config --global user.name "xxx"
git config --global user.email "xxx@xx.com"
```

- 拉取 SDK 代码（分支 release/v3.1.1.9）：

```bash
mkdir -p ~/shizhanpai_bk7258
cd ~/shizhanpai_bk7258
# GitHub 仓库
git clone --branch release/v3.1.1.9 https://github.com/bekencorp/bk_avdk_smp.git bk_avdk_smp_sdk
# 或 Gitee 仓库（无网络加速建议）
git clone -b release/v3.1.1.9 --depth 1 https://gitee.com/bekencorp/bk_avdk_smp.git
```

- 运行环境安装脚本（SOC 型号必须选择 **BK7258**）：

```bash
cd ~/shizhanpai_bk7258/bk_avdk_smp_sdk
sudo bash tools/env_tools/setup/armino_env_setup.sh
```

- Python pip 是否切换中文源时选择 N，等待安装完成即可

## Hello World 最小工程

### 创建工程

```bash
cd ~/shizhanpai_bk7258/bk_avdk_smp_sdk
mkdir -p ./demo/hello
cp -a ./projects/app/* ./demo/hello
cd ./demo/hello
```

只保留 BK7258，删掉无关内容：

```bash
rm -rf ap/config/bk7257_ap
rm -rf cp/config/bk7257
rm -rf partitions/bk7257
rm -rf .ci app.rst
rm -rf build
```

> 注意：AP 目标目录必须是 `bk7258_ap`，CP / 分区目标目录必须是 `bk7258`。

### 修正 Makefile 中的 SDK 路径

```makefile
SDK_DIR ?= $(abspath ../../)

PROJECT_MAKE_FILE := $(SDK_DIR)/tools/build_tools/build_files/project_main.mk
ifeq ($(wildcard $(PROJECT_MAKE_FILE)),)
$(error "$(PROJECT_MAKE_FILE) not exist, please check sdk directory.")
endif
include $(PROJECT_MAKE_FILE)
```

SDK 不在默认同级位置时，编译时覆盖：`make bk7258 SDK_DIR=/path/to/bk_avdk_smp_sdk`

### 让方案 components/ 参与构建

```cmake
cmake_minimum_required(VERSION 3.5)

# 避免无 git 时 cmake 去读版本失败
set(PROJECT_VER "1.0.0")

include($ENV{ARMINO_TOOLS_PATH}/build_tools/cmake/project.cmake)

set(EXTRA_COMPONENTS_DIRS
${CMAKE_CURRENT_SOURCE_DIR}/../../components
)

project(app)
```

### 精简 AP / CP 入口

ap/ap_main.c：

```c
#include "bk_private/bk_init.h"
#include <components/system.h>
#include <os/os.h>

#define TAG "Practical PI"

int main(void)
{
    bk_init();
    BK_LOGI(TAG, "READY: Hello Practical PI BK7258\r\n");
    return 0;
}
```

cp/cp_main.c：

```c
#include "bk_private/bk_init.h"
#include <components/system.h>
#include <os/os.h>
#include <modules/pm.h>
#include <driver/pwr_clk.h>

extern void rtos_set_user_app_entry(beken_thread_function_t entry);

void user_app_main(void)
{
    bk_pm_module_vote_boot_cp1_ctrl(PM_BOOT_CP1_MODULE_NAME_APP, PM_POWER_MODULE_STATE_ON);
}

int main(void)
{
    rtos_set_user_app_entry((beken_thread_function_t)user_app_main);
    bk_init();
    return 0;
}
```

ap/CMakeLists.txt：

```cmake
set(incs .)
set(srcs ap_main.c)

armino_component_register(
SRCS "${srcs}"
INCLUDE_DIRS "${incs}"
)
```

### 常见问题

| 问题 | 解决 |
| --- | --- |
| 找不到 SDK | 检查 Makefile 中的 SDK_DIR，或编译时显式传入 `SDK_DIR=/path/to/bk_avdk_smp_sdk` |
| cmake 报 grabRef.cmake / head-ref 错误 | 根 CMakeLists.txt 的 project(app) 之前加 `set(PROJECT_VER "1.0.0")` |
| 仍带有 BK7257 相关错误 | 确认已删除 bk7257 相关目录，且目标是 `make bk7258` |
| 方案 components 未被编译进去 | 确认设置了 EXTRA_COMPONENTS_DIRS，且组件目录含合法 CMakeLists.txt，业务侧 PRIV_REQUIRES 已声明 |
| 编译成功但没有 all-app.bin | 检查 build/bk7258/<工程名>/package/all-app.bin；向前查找分区、链接或打包阶段的第一条错误 |

### Web Flasher 常见问题（Q&A）

- **烧录失败常见原因**：
  - 板子未能自动进入烧录模式：日志提示需要按下 CEN/RST 按键时，按提示操作使板子进入烧录模式
  - 工作波特率过高：可将工作波特率降低至 1,000,000 后重新尝试
- **APP 波特率设置**：如果应用程序修改过 UART 波特率，需将"APP 波特率"修改为应用程序实际使用的值，该参数影响板子自动进入烧录模式

### 基于BK7258的灯带控制器

使用立创 BK7258 模组 C55863540，绘制灯带控制器原理图+2层PCB，严格遵守全部约束。

【整体功能清单】
1. 七彩通道：6路硬件同步PWM，固定频率16kHz；采用低侧NMOS、共阳驱动方案，适配输入5~24V恒压七彩灯带；PWM分配 PWM0~PWM5，禁止软件模拟PWM。
2. 幻彩三组独立对外端子：
   - 单线归零码 WS2811/SK6812：使用 SPI0（MOSI），必须加高速单向电平转换（3.3V→5V）
   - APA102/SK9822：使用 SPI0（SCLK + MOSI），同样增加高速3.3V→5V电平转换
   - DMX512：使用一路硬件UART + MAX485差分收发；单独一个GPIO控制 DE/RE；板上预留可选择焊接的120Ω终端电阻，差分对增加ESD；DMX固定波特率250000，8N2
3. 三个独立轻触按键：
   - KEY_POWER（电源开关，长按进入配网）：GPIO14
   - KEY_MODE（动画模式切换）：GPIO15
   - KEY_SPEED（速度/亮度循环调节）：GPIO16
   按键电路：按键一端接GND；GPIO串10k上拉电阻至模组3V3；

【电源设计规则】
输入VIN：5~24V；防护顺序：输入端子 → 慢熔保险丝 → PMOS理想二极管（防反接）→ SMAJ26CA TVS；之后分为两路：灯带功率回路、宽压DC-DC（TPS54202DDCR）降压输出5V再TLV62569DBVR降压输出3.3V供给模组。

【驱动与外设细节】
- PWM每一路：栅极串联100~220Ω电阻，紧贴MOS管；栅源并联10k下拉电阻；NMOS耐压≥40V；
- BK7258模组：保留模组自带26M晶振、射频天线；预留模组RST复位焊盘、SWD调试接口。
- 所有对外信号端子就近放置ESD器件、0.1uF滤波电容。
- BOM选用立创商城可采购器件，原理图网络命名清晰，每个通道添加中文注释。

【PCB布线强制规则】
1. 分区摆放：功率区（输入端子、保险、TVS、DC-DC、6路NMOS、七彩输出端子）、主控模组区、幻彩信号区、射频天线区分开；天线放置在板角落，严格净空，净空区内无铜、无走线、无器件；天线、射频馈线距离DC-DC电感、MOS功率回路≥8~10mm，射频馈线按50Ω阻抗控制，预留匹配网络焊盘。
2. 走线与电流（默认1oz铜厚）：功率主线按电流加宽，1mm≈1A；单路3A灯带走线≥3mm，大电流铜皮开窗上锡，走线圆角；MOS栅极走线尽量短；高速信号（WS DATA、SPI CLK/DATA、DMX差分对）远离DC-DC电感、PWM功率主线；DMX差分对等长、紧耦合布线；DC-DC电感正下方禁止铺信号地。
3. 按键布线：按键走线远离DC-DC电感、MOS功率走线，消抖电容靠近模组GPIO焊盘，不要放在按键端；信号线不跨过电感下方、不进入天线净空区。
4. 去耦与测试点：模组各VDD引脚就近布置0402 0.1uF去耦电容；全部关键节点放置测试点：VIN、3V3、GND、每一路PWM栅极、WS DATA、SPI CLK/DATA、DMX A/B、SWD、RST、三个按键。

【其他约束】
所有外设引脚不能冲突，一个引脚只能分配单一功能；原理图、PCB网络名称保持统一；输出两层板，常规工艺。
