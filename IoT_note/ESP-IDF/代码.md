# ESP-IDF 
![alt text](image-53.png)  
最主要的目录如下：
components:组件代码，esp-idf 的核心，包含通用的功能部件，比如 freeRTOS、wifi、GPIO
驱动、PWM 驱动等等
examples:官方例程，大部分的应用都可以在这里找到相关例子
docs:一些介绍文档
tools：一些工具，如编译、烧录

>头文件中只应该进行变量和函数的声明，而将变量的定义和初始化放在一个源文件中进行。这样可以避免重复定义的问题。  
>创建任务函数在app_main函数中调用。任务服务函数在main.c文件中定义,调用相关初始化函数后编写自己的程序逻辑。初始化函数写在（定义）对应.c文件里，需要对外界公开的话，在.h文件中声明。  
```
// 不推荐：在栈上分配大数组
int large_array[1000];

// 推荐：动态分配在堆上
int* large_array = (int*)malloc(1000 * sizeof(int));
```

# 代码笔记
```
//立创示例代码
#include <stdio.h>
#include <inttypes.h>
#include "sdkconfig.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

void app_main(void)
{
    printf("Hello world!\n");
    vTaskDelay(1000 / portTICK_PERIOD_MS);
    fflush(stdout);
    esp_restart();
}
fflush(stdout);：刷新标准输出缓冲区，确保所有输出都已发送到终端或串口。通常 printf 会将数据存入缓冲区，fflush 可以立即输出。

esp_restart();：调用 ESP32 的系统重启函数，重启芯片。程序在打印 "Hello world!" 后延时 1 秒，接着重启设备
```

## 重置配网
![alt text](image-45.png)  
![alt text](image-49.png)  
修改配网
调用`wifi_prov_mgr_reset_provisioning`  
`wifi_prov_mgr_reset_sm_state_on_failure()`  
nvs_flash_erase() 是 ESP-IDF 提供的一个函数，用于擦除 NVS（非易失性存储）分区中的所有数据。它的作用是将 NVS 分区恢复到未使用的状态，所有存储的数据都会被清除

wifi_prov_mgr_deinit() 是 ESP-IDF 中用于解除 Wi-Fi 配网管理器（Wi-Fi Provisioning Manager）的初始化的函数。当设备不再需要 Wi-Fi 配网功能时，可以调用该函数来释放资源并清理配网管理器的状态。

esp_err_t wifi_prov_mgr_reset_provisioning（void)
重置 Wi-Fi 配置。
调用此 API 会将 WiFi 堆栈持久设置恢复为默认值。
返回
ESP_OK ： 已成功重置 Provisioning 配置
ESP_FAIL ： 无法重置 Provisioning 配置
