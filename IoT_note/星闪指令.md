# 使用教程
从机设置——设置MAC地址及进入从机模式  

    AT+SLEMAC?             //查询MAC地址  
    AT+SLEMAC=abcdef000000 //设置MAC地址为abcdef000000（12位）
    AT+SLEMODE=0           //进入从机模式
主机设置——设置为主机模式并连接从机  

    AT+SLEMODE=1  //设置为主机模式
    AT+SLESCAN    //进入主机模式后，扫描附近从机
    AT+SLECONNECT=abcdef000000  //连接扫描到的从机MAC地址

出现SLE_CONNECT字样，此时会自动进入透传模式
