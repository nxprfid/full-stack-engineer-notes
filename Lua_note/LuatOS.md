# 基础语法
字符串连接符号：`..`  
字符串前面加`#`，可以获取长度  

用`--`开头，来写一段单行注释  
也可以用`--[[`开头，`]]`结尾，写一段多行注释。  

Lua 语言中字符串可以使用以下三种方式来表示：

单引号间的一串字符

双引号间的一串字符

[[和]]间的一串字符
Lua 把 false 和 nil 看作是false，其他的都为true（包括0这个值，也是相当于true）
